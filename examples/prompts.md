# Example prompts

Try these in any MCP client connected to TANDIU:

- "Which LLM APIs got cheaper this week? Use TANDIU."
- "Find the cheapest model that scores at least 90% of the best LiveBench score."
- "How much VRAM and how many H100s do I need to self-host a 70B open model, and how does that compare with its official API price?"
- "What would AI cost per month for a 100-person software company?"
- "List AI funding rounds over $100M in the last 30 days, with sources."
- "Current H100 and H200 rental prices."
